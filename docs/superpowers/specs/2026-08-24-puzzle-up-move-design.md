# 拼图上移修复设计

## 目标

按上键时，将空白格正下方的图片移动到空白格，并把空白格位置向下更新；空白格在最后一行时不执行移动且不越界。

## 数据语义

`data` 中的 `15` 是唯一的空白格标识。初始化必须保留所有 `0` 至 `15` 的随机值，并在发现 `15` 时记录其行列坐标。`0` 始终是第一块图片，不能用于表示空白格。

## 实现

1. 初始化循环无条件写入 `data[i / 4][i % 4]`，并在值为 `15` 时同步更新 `x`、`y`。
2. 上移前判断 `x < 3`。允许移动时，把下方数值赋给当前空白位置，将下方位置设回 `15`，再使 `x` 加一并重绘。
3. 修正背景缩放调用中误写的负宽度，使其使用 `508`。
4. 在空白标识和交换代码旁添加注释，说明 `15` 的语义与移动方向。

## 验收

- 初始网格包含且只包含一个 `15`。
- 上移后，下方图片占据原空白格，新的空白格为 `15` 且行号增加一。
- 空白格位于最后一行时按上键不改变数据且不抛出数组越界异常。
